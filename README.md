# 🏩 방 채우기 대작전 — 모텔에서 호텔까지

시골의 작은 모텔에서 시작해 도심 모텔, 비즈니스 호텔, 제주 리조트, 파리 그랜드 호텔까지 키워 가는 아케이드 경영 게임입니다.

## 플레이
브라우저에서 바로: **https://dydtjr13.github.io/motel-rush/**

- 🛎️ 손님 터치 → 빈방 터치로 입실
- 💬 말풍선 요청은 방을 터치해 비품 판매
- 🧹 나간 방은 빗자루·수세미·새 시트·봉투를 끌어다 청소
- 😤 진상 난동은 연타로 진정, 🪳 벌레는 연타, 💧📺 고장은 수리비
- 🌙 밤에는 발주 · 광고 · 시설 투자 · 승급

파일 하나(index.html)로 동작하며, 진행 상황은 브라우저에 저장됩니다.
